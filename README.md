# Академічний таймер / секундомір (45 / 5 / 45)

Додаток на базі **CustomTkinter** для обліку навчальних або робочих сесій за структурою:
- **Сесія 1**: 45 хвилин
- **Перерва**: 5 хвилин
- **Сесія 2**: 45 хвилин

Код повністю відповідає стандарту **PEP 8** та використовує лише `customtkinter` і вбудований звуковий модуль системи (`winsound` на Windows).

---

## Швидкий запуск

### 2. Встановлення залежностей (за потреби)
```cmd
pip install -r requirements.txt
```

### 3. Запуск програми
```cmd
python main.py
```

---

## Можливості
- **Два режими відображення**: зворотний відлік (таймер) або прямий відлік (секундомір).
- **Візуалізація етапів**: картки фаз із відображенням активної фази та статусу проходження.
- **Налаштування часу**: зміна тривалості фаз у вікні налаштувань або кліком по картках.
- **Прогрес-бар**: плавне відстеження прогресу поточної фази та загального часу сесії.
- **Керування**: Старт / Пауза, скидання поточної фази, скидання всього циклу, ручний перехід вперед/назад між етапами.
- **Автоперехід**: можливість автоматичного старту наступного етапу або зупинки на паузу.
- **Сучасний UI**: адаптивна підтримка світлої/темної теми системи через CustomTkinter.
